TEST CASES
------------------------------------------------------------
TC01 - Basic APB FIFO Write to UART -- PASS ✅
------------------------------------------------------------

Objective:
    Verify the basic APB -> FIFO -> UART data path.

Stimulus:
    Configure FIFO.
    Write one byte (for example 0x55) to FIFO through APB.

Expected Result:
    UART transmits 0x55.
    Scoreboard reports PASS.

------------------------------------------------------------
TC02 - Multiple FIFO Writes -- PASS ✅
------------------------------------------------------------

Objective:
    Verify multiple bytes are transmitted in the same order
    in which they were written.

Stimulus:

    APB writes:

        0x55
        0xA5
        0x3C

Expected Queue:

        [55][A5][3C]

Expected UART Output:

        0x55
        0xA5
        0x3C

TC07 - Invalid Address / PSLVERR -- PASS ✅
------------------------------------------------------------

Objective:
    Verify APB error handling for invalid addresses.

Stimulus:
    Perform an APB transaction to an invalid address,
    for example 0x0000_0040.

Check:

    - addr_valid
    - PSLVERR
    - FIFO state is not modified
    - No unexpected UART data is transmitted

Expected Result:
    PSLVERR is asserted for the invalid APB access.
    The invalid transaction does not write data into the FIFO.
    FIFO count/status remains unchanged.
    No unexpected UART transaction is generated.

TC09 - Reset During Active UART Transmission -- PASS ✅
------------------------------------------------------------

Objective:
    Verify DUT behavior when reset is asserted while
    FIFO/UART activity is in progress.

Stimulus:
    1. Write multiple data bytes into FIFO through APB.
    2. Wait until UART transmission starts.
    3. Assert PRESETn while uart_tx_busy = 1.
    4. Release reset.

Check:
    - FIFO count returns to 0.
    - empty = 1.
    - full = 0.
    - uart_tx_busy = 0.
    - uart_tx_o = 1 (UART idle).
    - Previous FIFO data is discarded.
    - No stale transaction remains after reset.

Expected Result:
    DUT immediately returns to its reset/idle state.
    FIFO contents are cleared logically.
    UART transmission is aborted cleanly.
    DUT can accept new APB transactions after reset.


------------------------------------------------------------
TC10 - FIFO Read Pointer Wrap-Around
------------------------------------------------------------

Objective:
    Verify that the FIFO read pointer wraps from the last
    valid FIFO entry back to address 0 correctly.

Stimulus:
    1. Configure FIFO depth to 8.
    2. Write enough data so that UART consumption advances
       r_ptr through all FIFO locations.
    3. Allow at least 8 FIFO-to-UART read handshakes.
    4. Continue transmission after r_ptr reaches depth-1.

Check:
    - r_ptr reaches 7.
    - After the next FIFO read, r_ptr wraps to 0.
    - UART data ordering remains correct.
    - Scoreboard reports no mismatches.

Expected Result:
    Read pointer wraps correctly from 7 to 0 without
    data loss or ordering errors.


------------------------------------------------------------
TC11 - UART Zero Baud Divider Boundary
------------------------------------------------------------

Objective:
    Verify DUT behavior when uart_baud_div is configured
    to zero.

Stimulus:
    1. Set uart_baud_div = 0.
    2. Write one valid byte into FIFO through APB.
    3. Allow FIFO -> UART transmission to occur.

Check:
    - UART does not hang.
    - UART transmission starts and completes.
    - UART monitor decodes the expected data correctly.
    - Scoreboard reports no mismatch.

Expected Result:
    DUT handles baud_div = 0 according to the RTL fallback
    behavior and completes UART transmission correctly.
